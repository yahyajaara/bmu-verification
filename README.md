# BMU Verification Project

UVM verification environment for the 32-bit RISC-V Bit Manipulation Unit.

## Project Scope

The project verifies 20 required BMU operations and CSR behaviors defined
by the BMU Verification Plan.

Detailed scope information is available in:

`docs/verification_scope.md`

## Project Structure

- `tb/` - UVM testbench files
- `top/` - testbench top
- `sim/` - simulation files, filelists, and testlists
- `docs/` - project documentation
- `reports/` - verification results and summaries

## Simulator

Cadence Xcelium will be used for compilation and simulation.

## Status

Project setup and verification architecture are currently in progress.
